CARA REDEPLOY DI VPS BARU
-------------------------
1. Extract ZIP ini ke  C:\Quant
   Path ini WAJIB persis — di-hardcode di watchdog, semua .bat, dan pipeline/live/signal.py
2. Install Python 3.11 ke C:\Program Files\Python311
   (path ini juga di-hardcode di file .bat)
3. pip install -r requirements.txt
4. Install MetaTrader 5, login FBS-Demo
5. MT5: Tools > Options > Expert Advisors > centang WebRequest, tambahkan
      http://127.0.0.1:8000
6. Copy mt5_ea/SignalExecutor.mq5 ke folder MQL5\Experts di data dir MT5,
   attach ke chart XAUUSD, nyalakan Algo Trading (Ctrl+E)
7. Jalankan watchdog:
      powershell -ExecutionPolicy Bypass -File C:\Quant\_MONITOR\watchdog_shadow.ps1
